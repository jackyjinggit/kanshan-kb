# 原创摘要

指引列出了创作中心的数据入口：内容分析可查看阅读、播放和赞同、评论、喜欢、收藏等互动及趋势；收益分析可查看收益、余额、分日列表和内容收益。用户还可以管理公开内容、关注和收藏，并通过相应功能管理、删除信息或撤回授权。

# 可支持与不能支持

- 支持：作品、互动、收益是不同数据域；需核验本人具体页面和权限。公开互动不等于已同意加入外部社群或订阅营销。
- 不支持：每个账号都能看到所有指标、接口字段与网页完全一致、开放 API 能返回任意历史数据、创作者自动获得用户联系方式。
- 该文件规定知乎自身的数据处理方式，不能替代第三方项目的隐私说明或法律评估；本知识库从中借鉴目的明确、必要收集、用户可控制的产品设计原则。

## 用途与用户控制

第 5.2 版说明收集和使用目的、用途变化的告知与同意，并提供访问、更正、删除及撤回同意等管理机制。可借鉴用途透明、必要收集及用户可控制的设计原则；不能把一次授权当作永久无限访问。指引不授予第三方全文下载、训练或任意再分发许可，也不证明某个开放接口存在撤销端点或本项目已经接通 OAuth。

## 个性化推荐与搜索

指引说明，个性化展示会使用浏览使用记录等信息；站内搜索会记录查询词及搜索结果点击，用户可以关闭个性化内容推荐。因此方法引擎应区分推荐、搜索、后台统计与接口权限，分别记录入口和口径。

该指引没有披露赞同、收藏、评论的排序系数，也没有承诺黑客松 API 提供任何指定字段或精确小时粒度。浏览器登录、后台可见和开放 API 可用是三个不同条件；它不是第三方采集授权或全部用户数据的开放许可。

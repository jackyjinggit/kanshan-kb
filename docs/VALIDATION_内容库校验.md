## 本轮修复与验证

- 发布时间方法改为比较相同实际发布年龄的完整窗口。独立复核合成反例：08:00 与 20:00 发布的后续七个自然日可分别为 240/348，但精确首 168 小时均为 384；缺同龄窗口时不能判断时段优劣。该项是方法正文及算例验证，不是线上增长实验或应用算法测试。
- 可选 `evidence_level` 若存在必须为非空字符串；递归 YAML 序列、NaN、Infinity 被拒绝。查询序列化包含在异常处理内并禁止非有限数字，失败返回严格可解析的安全 JSON。缺省字段仍返回 `null`。
- 重建工具逐项处理清理失败，保留已经写入的 README 路径及最初错误。临时副本中真实目录权限故障复验：第一份 README 替换成功、第二份替换和清理同时失败时，`written` 与实际变化一致，并报告残余暂存文件；另一清理失败不妨碍继续清理其他文件。
- 导航链接与图片目标分开：仅图片引用不能充当知乎案例、M4 写作真源或别名跳转；真实图片外层链接有效，图片替代文本中的伪链接无效，图片目标仍检查。查询 `references` 保持字符串数组契约。
- 50 项工具回归测试通过，包含原有 41 项及本轮新增 9 项；CLI 响应测试使用拒绝 NaN/Infinity 的严格 JSON 解析。原 v0.3 审计脚本在临时副本复跑，11 条记录含基线、故障场景与恢复检查，确认上述故障被修复；不将这些记录混计为 11 个新增单测。
- 结构校验、全量 28 篇正文查询、FILELIST 重建及只读检查通过。方法 ID、38 张来源卡、3 个别名、3 篇写作真源均保留；本轮正文仅修改 M6-02。

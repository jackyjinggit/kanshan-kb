# 看山优化·创作校准引擎 — 自媒体运营方法论知识库

黑客松作品「看山优化 / 创作校准引擎」的**方法论层**。

## 为什么需要它

看山（创作校准引擎）已有「数据接入层 + 呈现层」，但缺**方法论层**——只吐数据列表，给不出完整运营建议。
本仓库补上方法论大脑：把数据 symptom → root cause → 完整动作。

## 结构

10 个模块（M1–M10），每个模块一个目录，含 README（文件清单 + 待填方法清单）：

| 模块 | 名称 | 要点 |
|---|---|---|
| M1 | 定位与赛道选择 | 三维定位法 / 人设黄金三角 / 内容缺口挖掘 |
| M2 | 人设与账号包装 | 账号5件套 / 价值承诺句式 |

| M6 | 发布与冷启动运营 | 12条垂直打标签 / 发布时机 / 冷启动互动引导 |

## 填写规范

每篇方法 md 带 frontmatter：

```yaml
---
title: 方法名
type: method
适用平台: 知乎(专项)
适用阶段: 冷启动/成长期/成熟期/全阶段
数据信号: 触发本方法的异常数据特征
---
```

正文建议结构：**方法定义 → 操作步骤（可复制） → 知乎实证/案例 → 常见错误**。

## 看山消费格式

每条建议 = ① 诊断（哪个环节出问题）→ ② 处方（具体 1–3 个动作）→ ③ 依据（链接到本方法 md，可证伪、可直读全文）。

## 与本地 vault 的关系

本地 `知识库/自媒体运营方法论/` 为工作真源；本仓库为**脱敏发布子集**（黑客松提交物），二者分离、不互相污染。

## 平台专项

知乎（黑客松限定）。知乎三路分发、互动权重、盐选逻辑必须写实，不泛泛而谈。

## 本地维护

填实方法 md 后，重跑 `_scripts/kb_index_rebuild.py` 刷新各 README 的 FILELIST 块（需从 vault 复制最新到本仓库）。
